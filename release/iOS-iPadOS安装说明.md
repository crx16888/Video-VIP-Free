# VIP视频解析 iOS/iPadOS 安装说明

## 方式一：Safari 添加到主屏幕

1. 在 iPhone 或 iPad 上用 Safari 打开：https://vip-video-parser-sepia.vercel.app/
2. 点击 Safari 底部或顶部的分享按钮。
3. 选择「添加到主屏幕」。
4. 点击「添加」后，即可像普通 App 一样从主屏幕打开。

## 方式二：安装 WebClip 描述文件

1. 在 iPhone 或 iPad 上下载 `VIP视频解析-iOS-iPadOS-WebClip.mobileconfig`。
2. 打开「设置」，进入已下载的描述文件。
3. 按提示安装。
4. 安装完成后，主屏幕会出现「VIP解析」图标。

## 说明

这是 PWA/WebClip 下载版本，不需要 Apple Developer 证书。若需要可直接安装的 `.ipa`，需要提供 Apple Developer 账号、签名证书，并新增或生成 iOS 原生工程后再打包。
