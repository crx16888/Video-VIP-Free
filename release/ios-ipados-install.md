# VIP Video Parser iOS/iPadOS Install

## Safari

1. Open https://vip-video-parser-sepia.vercel.app/ in Safari.
2. Tap Share.
3. Choose Add to Home Screen.
4. Tap Add.

## WebClip Profile

1. Download `vip-parser-ios-ipados-webclip.mobileconfig` on your iPhone or iPad.
2. Open Settings and install the downloaded profile.
3. After installation, the `VIP解析` icon appears on the Home Screen.

This is a PWA/WebClip package and does not require Apple Developer signing. A native `.ipa` requires an Apple Developer account, certificates, and an iOS app archive.
